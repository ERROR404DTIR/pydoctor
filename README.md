# 🩺 PyDoctor

A read-only Python environment diagnostic. It helps identify which interpreter is running, whether a virtual environment is active, where packages are searched, and whether key standard-library modules are available.

## Run

```bash
python pydoctor.py
python pydoctor.py --json
```

No `pip`, no dependencies, no administrator privileges. It does not install, remove, or modify anything.

Requires Python 3.8+.
